three.js — TSL compute attractors particles

WebGPU TSL compute particles orbiting three gravitational attractors, with spinning force, speed-mapped colour, and looping bounds. Based on the Three.js WebGPU TSL compute attractors particles example by Bruno Simon.

<> View source code on GitHub

WebGPU required

This demo uses WebGPU compute shaders to simulate hundreds of thousands of particles. Open it in a browser with WebGPU support (Chrome 113+, Edge 113+, or Firefox Nightly with WebGPU enabled).
