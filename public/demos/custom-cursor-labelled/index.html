Labelled custom cursor

Parked v1 of the IOM pointer — precision tip, inertial ring, and context labels. The live site now uses a quieter focus orb on cards; this demo keeps the labelled system for reference.

Playground Hover targets
ENTER 3D data-cursor="explore" · data-cursor-label="ENTER 3D"
VIEW Project / gallery
PLAY Video / audio
LOOK 360° panorama
DRAG Hold to see MOVE
START Primary contact CTA EXTERNAL Diagonal arrow LINK Ordinary link (no label)
Usage data-cursor 
<!-- Assign states declaratively -->
<a
  href="/demos/panorama-360/"
  data-cursor="look"
>
  Open tour
</a>

<article
  data-cursor="explore"
  data-cursor-label="ENTER 3D"
>
  …
</article>

<button data-cursor="start">
  Get in touch
</button>

/* Modes */
view | play | pause | explore
look | drag | start | external | link

/* Motion */
dot  → fast track (lerp ~0.55)
ring → soft inertia (lerp ~0.16)
