# WDA Booth Preview

Independent static Three.js walkthrough adapted from the reviewed 28 October local study. Run `npm run build`, then `npm start`; open http://127.0.0.1:5193/demos/wda-booth-preview/. No install or account required.

Published runtime: https://iobjectm.com/demos/wda-booth-preview/. Original local version remains untouched. Only public runtime and viewer source are packaged; Blender files, internal notes and inspection evidence are excluded. Model, photographs and existing floor textures are retained with user confirmation for this release on 2 November 2026. Three.js and Draco license notices remain in public/vendor and public/decoders.

Walk with WASD/arrows and drag to look; Escape exits. View settings controls floor material, wall color, light, shadows and optional floor reflections. No account uploads or persistence beyond local floor selection.
